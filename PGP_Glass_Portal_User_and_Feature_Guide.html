1. Welcome & Introduction

Welcome to the official PGP Glass Apprentice Portal User Manual. This system serves as the single source of truth for managing all NAPS and NATS apprentices across PGP Glass manufacturing facilities in Kosamba, Halol, and Jambusar.

The portal empowers HR teams to track active enrollments, perform bulk spreadsheet uploads without introducing duplicate records, log official program completion sign-offs with strict audit trails, and export custom compliance reports in multiple formats.

2. User Roles & Permissions Matrix

The portal enforces strict Role-Based Access Control (RBAC) to maintain security and plant location data privacy:

4.3 Apprentice Completion Sign-Off Workflow

When an apprentice finishes their training tenure, Branch HR managers must execute a formal completion sign-off:

1
Open Completion Modal: Locate the apprentice in the Active Registry and click Mark Completion.
2
Select Completion Reason: Choose the appropriate completion category: Completed, Resigned, Terminated, or Transferred.
3
Enter Quality Remarks: Type detailed HR remarks explaining the completion context.
Validation Rule

Remarks must be at least 10 characters long. Generic placeholder words (such as 'ok', 'done', 'completed', 'test') are strictly rejected by the portal.

4
Confirm & Lock: Upon clicking Submit, the apprentice is deleted from Active_Apprentices, appended to Completed_Apprentices, and logged in the audit trail.

4.4 Bulk Excel Import Center (Super HR Admin)

Importing monthly master spreadsheets is governed by an automated 3-step reconciliation engine:

Figure 4.2 — Three-Step Bulk Excel Reconciliation & Commit Workflow

Reconciliation Rules to Remember:

  • Duplicates Blocked: Records matching existing active apprentices by Employee Code or Contract ID are updated rather than duplicated.
  • Completed Apprentices Protected: Apprentices already in the completed archive are locked. Uploading their row in an Excel file will not accidentally reactivate them.
  • Unchanged Rows Skipped: If an incoming row contains identical data to what's already in the database, it is processed without inflating the Updated count metric.

4.5 Custom Report Builder & Data Exporter

The Reports module allows HR teams to build customized, exportable reports:

1
Select Scope: Choose report target: Active Apprentices, Completed Apprentices, or All Master Records.
2
Set Filters: Filter by specific plant location (Kosamba, Halol, Jambusar) and date ranges.
3
Select Columns: Check or uncheck specific data columns (e.g. Employee Code, Name, Contract ID, Enrollment No, Joining Date). Your column selections are saved automatically in your browser.
4
Export Format: Click your desired format button:
  • Export CSV: Standard comma-separated text file for raw data analysis.
  • Export Excel: Formatted .xlsx binary spreadsheet workbook.
  • Export PDF: Executive PDF document formatted for clean landscape printing.

4.6 User Account Console (Super HR Admin Only)

Super HR Administrators can navigate to Users to manage system access:

  • Add HR Account: Enter Name, Email, Password, assign Role (Super HR Admin or Branch HR), and select Plant Location.
  • Edit Account: Modify user roles or reassign branch locations.
  • Reset Password: Instantly issue a new encrypted password for an HR team member.
  • Deactivate Account: Instantly revoke system access without deleting historical audit logs.

5. Frequently Asked Questions (FAQ) & Troubleshooting

Q: Why can't I see apprentices from other plant locations?

A: If your account has the Branch HR role, your view is strictly restricted to your assigned branch (e.g., Kosamba). Only Super HR Admin accounts have company-wide access across all plants.

Q: Why did my completion remark get rejected?

A: The system enforces quality control on sign-off remarks. Remarks must be at least 10 characters long and cannot consist of generic words like 'ok', 'done', or 'completed'. Provide meaningful context (e.g., "Completed 1-year NAPS training tenure successfully with good performance.").

Q: What happens if an uploaded Excel file contains missing fields?

A: During the Phase 1 Dry-Run, the system flags invalid rows and increments the Rejected count metric. The detailed modal table highlights exact rejected row numbers and reason messages so you can correct the file before committing.

6. HR Operational Best Practices & Data Hygiene Guidelines

Recommended HR Workflow
  1. Perform monthly Excel uploads promptly at the beginning of each intake cycle.
  2. Review Dry-Run summary statistics carefully before clicking "Confirm & Import".
  3. Process apprentice completion sign-offs immediately when trainees finish their contracts to maintain accurate active counts.
  4. Never share login credentials; each HR team member should operate under their dedicated account for complete audit traceability.
